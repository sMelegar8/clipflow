ClipFlow

Privacy Policy

Last updated: 17 November 2026

ClipFlow is a personal tool used by a single owner to upload videos to the owner's own YouTube channel. It is not offered to other users.

Data accessed

With the owner's explicit consent through Google OAuth, ClipFlow requests these YouTube scopes only:

  • youtube.upload: to upload videos to the owner's channel;
  • youtube.readonly: to read the ID of the authorised channel, so that videos are never uploaded to a different channel.

ClipFlow does not read, collect or store any data about other YouTube users, viewers or subscribers.

Storage

The OAuth refresh token is stored only on the owner's computer, encrypted with Windows Data Protection (DPAPI). Upload records (file hash, video ID, date) are kept in a local database on the same computer. No data is sent to any server other than Google's YouTube Data API.

Sharing

ClipFlow does not sell, share or transfer Google user data to anyone. Google user data is used only to upload the owner's videos, in line with the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time from Google Account permissions. Deleting the local token file removes ClipFlow's stored access.

ClipFlow uses YouTube API Services. See the YouTube Terms of Service and the Google Privacy Policy.
